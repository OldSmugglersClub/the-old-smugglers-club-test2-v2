# CREWDUELL FULLCOMPOSITION TEST2

Ziel: Desktop und Mobile sollen wie eine zusammenhängende Crewduell-Grafik wirken,
ohne wechselnde Werte in ein statisches Bild einzubrennen.

Prüfen:
- Desktop: Motiv + Teamfelder bilden optisch eine Einheit.
- Mobile: Motiv bleibt vollständig nutzbar, Teamfelder folgen direkt darunter.
- Keine doppelte Zeile unter `Crew gegen Crew`.
- Dynamische Teamnamen und Durchschnittswerte unverändert.
