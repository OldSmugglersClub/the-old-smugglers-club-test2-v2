TOSMC – EINMALIGE BEREINIGUNG DES VERWORFENEN TERMINWAECHTERS
Nur TEST2v2. KEIN LIVE. Stand 28.10.2026.

ZWECK
Der am 28.10.2026 verworfene Terminwaechter (TEST1 bis TEST28 als
Entwicklungsstrang) wird aus TEST2v2 entfernt. Die funktionierenden
Bundesliga-, Dynamo-, Schutz- und sonstigen Betriebs-Workflows bleiben erhalten.
Alte Logbuch-TEST-Dateien bleiben ebenfalls erhalten.

EINSPIELEN
1. GitHub Desktop: TEST2v2-Repository aktualisieren (Fetch/Pull).
2. Die ZIP in einen Ordner entpacken.
3. Nur die vier folgenden Dateien mit ihren Ordnern ins TEST2v2-Repo kopieren:
   .github/workflows/tosmc-terminwaechter-bereinigung-einmalig.yml
   scripts/tosmc-terminwaechter-bereinigung-einmalig.py
   cleanup/terminwaechter-entfernen.json
   ANLEITUNG_TERMINWAECHTER_BEREINIGUNG.txt
4. In GitHub Desktop muessen genau diese vier neuen Dateien erscheinen.
5. Commit und Push origin.

AUSFUEHREN (kein Terminal, keine CMD-Befehle!)
1. In GitHub Actions den Workflow
   'TOSMC – Terminwaechter einmalig bereinigen (nur TEST2v2)' auswaehlen.
2. Run workflow / Arbeitsablauf ausfuehren, Branch main.
3. Modus TROCKENLAUF (Standard). Freigabetext leer. Starten.
4. Der Lauf muss GRUEN sein und 'Nur geprueft' anzeigen.
5. Erst danach erneut starten:
   Modus ENTFERNEN
   Freigabetext: TERMINWAECHTER_VERWORFEN_TEST2V2
6. Der zweite Lauf entfernt exakt die 59 festgelegten Altdateien
   (vier alte Terminwaechter-Workflows, exklusive Skripte und README-Dateien,
   ausserdem den Bereinigungs-Workflow inkl. seiner eigenen Hilfsdateien).
   Anschliessend wird EIN Commit auf TEST2v2/main gepusht.
7. Der Handover-Nachtrag TOSMC_TERMINWAECHTER_VERWORFEN_2026-10-28.md
   wird als einziger neuer dauerhafter Projektvermerk hinterlassen.
8. GitHub Desktop anschliessend einmal Fetch/Pull ausfuehren.
