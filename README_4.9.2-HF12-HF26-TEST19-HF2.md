# README – 4.9.2-HF12-HF26-TEST19-HF2

Testversion für den bestehenden Menüpunkt **Landgang**.

Ziel dieser HF2 ist ausschließlich die Korrektur von Tempo und Sound-Synchronisation aus TEST19-HF1.

Erwarteter Ablauf:
1. Offene Truhe / Schatz sichtbar.
2. Fließender Übergang zur halbgeschlossenen Truhe mit Holzknarren.
3. Beschleunigtes finales Zuklappen.
4. Exakt beim vollständig geschlossenen Zustand: Knall/Impact.
5. Kurzer Nachhall, Abdunkeln, Schließversuch/Fallback.

Gesamtdauer: ca. 2,75 Sekunden.
