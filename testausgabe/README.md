# Testausgabe

Dieser Ordner ist ausschließlich für neu erzeugte TestAdmin-Ausgaben vorgesehen.

Wichtig:
- Keine alten Testwerte wurden aus dem bisherigen Test2-Repository übernommen.
- Produktive `*.json` im Repository-Stamm entsprechen der sauberen Website-Basis 4.9.2-HF1.
- Testausgaben dürfen nicht ungeprüft als normale produktive JSON-Dateien übernommen werden.
