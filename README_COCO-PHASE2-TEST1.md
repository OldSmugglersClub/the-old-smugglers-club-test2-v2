# COCO-PHASE2-TEST1 – Prüfplan

1. Wettbewerbsseite mit Partie innerhalb 7 Tagen öffnen.
2. Nur dort muss `Coco fragen` erscheinen.
3. Link öffnen: exakt diese Partie muss auf Coco bereits ausgewählt sein.
4. Tipp darf erst nach normalem Klick auf Coco enthüllt werden.
5. Partien >7 Tage, laufende, beendete und nicht bestätigte Partien dürfen keinen Coco-Link zeigen.
6. Desktop und Mobile prüfen.
7. Spielplanfilter und Tippverteilung müssen unverändert funktionieren.
