TEST2v2 Installation:
1. Repository und wettbewerb.js sichern.
2. wettbewerb.js aus diesem ZIP ins Test2v2-Repository kopieren.
3. Im Root des Test2v2-Repositorys ausführen:
   python cache-kennung-test2v2.py .
   (benötigt Python 3; stoppt, falls eine HTML-Datei oder Referenz fehlt)
4. GitHub Desktop: Diff prüfen (JS nur DFB-Funktion; HTML nur Cache-Version), Commit/Push.
5. GitHub Release Guard abwarten; bei Fehler NICHT live übernehmen.
6. Browser in Test2v2: beide Hauptrunden ein-/ausklappen, Paarungen/Ergebnisse,
   Achtelfinal-Wertung und Bundesliga/CL unverändert prüfen.
