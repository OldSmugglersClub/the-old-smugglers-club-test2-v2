# TOSMC TEST2-v2 – Originalwappen Ringkorrektur

Basis: freigegebener TEST3-CURRENT52-Projektstand.

Ziel: Originalwappen ohne kreisförmige Schmugglersiegel-Maskierung. Fallback-Schmugglersiegel bleiben unverändert.

Test: Desktop und Mobile; runde, schildförmige und schmale/rautenförmige Originalwappen sowie mindestens ein absichtlich ausgelöstes Fallback-Siegel prüfen.
