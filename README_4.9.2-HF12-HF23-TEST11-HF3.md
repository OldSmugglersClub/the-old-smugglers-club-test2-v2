# 4.9.2-HF12-HF23-TEST11-HF3

Test-Hotfix für Test2-v2.

Zweck: Keine unvollständige Champions-League-Tabelle als reguläre Tabelle anzeigen.

Die OpenLigaDB-Daten werden weiterhin bei jedem Laden geprüft. Solange weniger als 36 eindeutige Teilnehmer erkannt werden, bleibt die Tabelle verborgen und zeigt einen Statushinweis. Ab 36 Teilnehmern erscheint sie automatisch.

Basis: 4.9.2-HF12-HF23-TEST11-HF2
Ziel: ausschließlich Test2-v2.
