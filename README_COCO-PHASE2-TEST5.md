# COCO-PHASE2-TEST5 – Prüfplan

1. Bundesliga und Dynamo Dresden öffnen.
2. `TERMINIERT` darf pro Spiel nur einmal erscheinen.
3. Bei Coco-fähigen Spielen muss `Coco fragen` weiterhin vorhanden sein.
4. Spiele außerhalb des 7-Tage-Fensters dürfen keinen Coco-Link erhalten.
5. Beendete und nicht zeitgenau terminierte Spiele dürfen keinen Coco-Link erhalten.
6. `Coco fragen` → exakte Partie vorausgewählt → `Zurück zum Spiel` führt zurück zur Ausgangspartie.
