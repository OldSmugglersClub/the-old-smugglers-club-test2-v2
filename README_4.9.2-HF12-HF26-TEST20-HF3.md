# README – TEST20-HF3

Testziel: Mehrwert der Kicktipp-Integration sichtbar prüfen.

## Ablauf
1. Clubseite öffnen.
2. Im Bereich „Die nächsten 7 Tage“ auf **Kicktipp Live Action** klicken.
3. Die TOSMC-Integrationsseite öffnet sich.
4. Kicktipp soll direkt die **Tippübersicht** laden.
5. „Kicktipp direkt“ bleibt als unabhängiger Originalzugang erhalten.

Die Kicktipp-Einbettung bleibt technisch isoliert auf `kicktipp.html`. Die Clubseite selbst hängt nicht vom Kicktipp-Script ab.
