# TEST22 – Mobile Kicktipp-Aktionsleiste

TEST22 prüft die einzeilige Darstellung der drei Kopfaktionen auf schmalen Smartphones.

## Testablauf

1. UPDATE in Test2-v2 installieren und die Seite hart neu laden.
2. `kicktipp.html` auf dem Smartphone öffnen.
3. Prüfen, dass „Zur Clubseite“, „Frage Coco“ und „Kicktipp direkt“ in einer Zeile stehen.
4. Prüfen, dass kein Text abgeschnitten wird und kein horizontaler Überlauf entsteht.
5. Alle drei Buttons anklicken und ihre Ziele kontrollieren.
6. Desktop-Darstellung kurz gegenprüfen.

Noch keine Live-Freigabe. TEST22 bleibt aktiv, bis der Nutzer den Test ausdrücklich bestätigt.
