# COCO-TEST6

Isoliertes Coco-Modul für den Test2-Integrationsstand.

Feste Regeln:
- echter lokaler Blau-Gelber-Ara-Ruf, keine synthetische Sprache;
- „Hmmm …“ ausschließlich visuell;
- interaktive Auswahl nur für konkrete, terminierte Partien innerhalb der nächsten 7 Tage;
- gleiche Spiel-ID erzeugt weiterhin denselben Coco-Tipp;
- Bilanz wird weiterhin aus dem vollständigen bestätigten 90-Minuten-Datenbestand berechnet.
