# Rollback TEST18 → TEST16

Dieses Update setzt ausschließlich die Intro-Änderungen aus TEST18 zurück und stellt den getesteten TEST16-Stand wieder her.

## Einspielen
1. `index.html` und `VERSION.txt` ersetzen.
2. Die unter „Löschen“ genannten TEST18-Dateien entfernen.
3. Danach Browser-Cache mit Strg+F5 aktualisieren.

Zielversion: `4.9.2-HF12-HF23-TEST16`.
